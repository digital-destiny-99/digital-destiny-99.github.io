Ozzy and The Tall Man

A text-based game about movement, choices and feedback. I built this project to practice Python logic while thinking about how a player moves through a simple interactive system.

Problem

02

The goal

Build a working text adventure where the player can explore a neighborhood, collect clues and reach a final ending only after completing the right steps.

The UX challenge

Text games can become confusing fast. The player needs clear room descriptions, obvious commands, useful feedback and a sense of progress without a visual interface doing the work.

System

03

Map structure

Rooms are organized in a dictionary so each location has a description, exits and a possible item.

Player commands

The game accepts short commands like north, inventory, map and get item. This keeps interaction simple and learnable.

Inventory logic

Items disappear after pickup and stay in the player inventory, which gives the player visible progress through the game.

Final room logic

The haunted tree house checks whether the player has every required item. If not, the game sends Jesse back with feedback instead of ending abruptly.
